使用指南

了解如何使用 CN-Codex 提高 your 开发效率

概述

CN-Codex 是一款强大的 AI 编程助手桌面应用，支持多种 LLM 供应商，内置丰富的工具能力，帮助你完成各种编程任务。

开箱即用

下载 CN-Codex 后，双击 CN-Codex.exe 即可启动，无需安装。首次启动需要配置 LLM 供应商的 API Key。

首次启动

1. 启动应用

双击 CN-Codex.exe 启动应用。首次启动时，应用会在当前目录创建 codey 文件夹用于存储配置和会话数据。

2. 配置 API Key

在开始使用前，需要配置至少一个 LLM 供应商的 API Key。打开设置面板，进入"供应商配置"部分：

codey/config.toml 
# OpenAI 配置示例
[providers.openai]
name = "OpenAI"
api_key = "sk-..."
base_url = "https://api.openai.com/v1"

# Anthropic 配置示例
[providers.anthropic]
name = "Anthropic"
api_key = "sk-ant-..."
base_url = "https://api.anthropic.com"

# 默认模型
model = "gpt-4o"

3. 目录结构

CN-Codex 运行时会在可执行文件同目录创建以下结构：

cn-codex/
├── CN-Codex.exe          # 主程序
├── codey/                # 运行时目录
│   ├── config.toml       # 配置文件
│   ├── sessions/         # 会话数据
│   ├── skills/           # 技能定义
│   ├── plugins/          # 插件目录
│   ├── memories/         # 记忆存储
│   └── usage.db          # 用量统计
└── node/                 # Node.js 便携版（用于 Shell 工具）

基本使用

对话界面

CN-Codex 提供直观的聊天界面：

  • 左侧边栏：会话列表，可搜索、归档、分叉
  • 中间区域：消息列表，支持 Markdown 渲染
  • 底部输入：输入框，支持多行文本
  • 右侧面板：工具调用详情、文件变更等

发送消息

按 Shift + Enter 可以换行而不发送消息。

在输入框中使用斜杠命令快速执行操作：

审批策略

CN-Codex 在执行敏感操作前会请求用户审批，确保安全可控。

策略类型

策略 说明
suggest 建议审批，大多数操作需要确认（推荐）
auto-edit 自动批准文件编辑操作
auto-run 自动批准命令执行
注意

auto-run 策略会自动执行所有命令，请仅在可信环境中使用。

对话模式

CN-Codex 提供两种对话模式：

Chat 模式

默认模式，适合一般对话和问答。AI 会根据需要调用工具，但不会自主执行多步骤任务。

Goal 模式

设置目标后，AI 会自主规划并执行多步骤任务：

  1. 分析目标，制定计划
  2. 逐步执行，调用工具
  3. 遇到问题自动调整
  4. 完成目标后汇报结果
Goal 模式示例 
用户：创建一个 React 计数器组件，包含增减按钮和重置功能

AI：
1. 创建 Counter.tsx 文件
2. 实现 useState 状态管理
3. 添加增减和重置按钮
4. 编写样式
5. 完成！

已创建文件：src/components/Counter.tsx

Goal 模式详解

设置目标

在输入框中描述你想要完成的任务，AI 会自动分析并制定执行计划。

执行过程

Goal 模式下，AI 会：

  • 调用 update_plan 更新任务计划
  • 使用 shell 执行命令
  • 使用 read_file 和 write_file 操作文件
  • 使用 code_review 审查变更
  • 使用 spawn_agent 启动子代理并行处理

监控进度

右侧面板显示当前任务进度、工具调用状态和文件变更列表。

中断与恢复

随时可以点击"停止"按钮中断当前任务。中断后会话状态会保存，可以继续对话。

移动端使用

CN-Codex 支持通过手机浏览器访问。

启动移动服务器

  1. 在应用中点击"移动服务器"按钮
  2. 查看显示的二维码和连接 URL
  3. 手机扫描二维码或在浏览器输入地址

技术原理

  • 内置 Web 服务器（Axum 框架）
  • WebSocket 实时通信
  • 局域网设备发现
安全提示

移动服务器仅在局域网内可用，请勿在公共网络中开放。建议设置访问密码。

MCP 协议

CN-Codex 支持模型上下文协议（MCP），可以连接外部 MCP 服务器扩展能力。

配置 MCP 服务器

# codey/config.toml
[mcp.filesystem]
command = "npx"
args = ["-y", "@modelcontextprotocol/server-filesystem", "/path/to/allowed/dir"]

[mcp.postgres]
command = "uvx"
args = ["mcp-server-postgres", "postgresql://localhost/mydb"]

常见问题

Q: 如何切换语言？

在设置面板中可以选择中文或英文界面。

Q: 会话数据存储在哪里？

会话数据存储在 codey/sessions/ 目录，以 JSONL 格式保存。

Q: 如何查看 Token 用量？

用量数据存储在 codey/usage.db SQLite 数据库中，可在设置面板查看统计。

Q: 支持哪些操作系统？

目前仅支持 Windows 10 及以上版本。macOS 和 Linux 版本计划中。

Q: 如何更新？

从 GitHub Release 下载最新版本，替换可执行文件即可。会话数据会自动兼容。
