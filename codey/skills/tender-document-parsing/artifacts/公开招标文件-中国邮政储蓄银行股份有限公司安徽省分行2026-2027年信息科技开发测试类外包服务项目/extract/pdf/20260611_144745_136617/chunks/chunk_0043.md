第三条 履约保证
本协议选择 3.2 条列明的方式进行履约保证。
3.1 履约保证金。本协议签订后 / 天内，乙方将履约保证金汇入甲方指定账户，金额
为[ 框架协议累积支付上限/ 乙方中标份额] 的 / % ，即：人民币 / 元整
（￥ / ）。
3.1.1 若乙方未按约定及时足额缴纳履约保证金，经催告后仍不缴纳的，则甲方有权终止本协
议。
3.1.2 乙方应于[质保期到期后/协议有效期到期后/交付成果验收通过后] 天内向甲方提交履
约保证金退还申请书。
3.1.3 如经甲方核实，乙方在履约过程中未发生需扣除履约保证金的违约行为，甲方应于乙方
提交履约保证金退还申请书后 / 日内全额退还履约保证金（无息）至乙方指定账户。
3.1.4 如经甲方核实，乙方在履约过程中发生了需扣除履约保证金的违约行为，甲方应根据协
议相关条款约定予以扣除，并于扣除金额核算完成后 / 日内通知乙方扣除情况。乙方应于收到
甲方通知后 / 天内向甲方提交履约保证金退还申请书，甲方应于乙方提交履约保证金退还申请
书后 日内退还扣减后的履约保证金（无息）至乙方指定账户。
3.2 履约保函。本协议签订后 30 天内，乙方向甲方提供一份由银行出具的不可撤销的
履约保函，一份原件，一份复印件。该保函以甲方为受益人，金额为人民币壹拾万元整
（￥ 100000 ）
3.2.1 履约保函有效期自生效之日起至本协议约定的服务期届满后12 个月。
3.2.2 因乙方原因导致本协议服务期限延长的，履约保函有效期应同步相应延长，延长期间的
担保费用及相关手续由乙方自行承担。甲方有权要求乙方重新出具或续展保函，直至服务全部完成、
验收合格且质保期届满。
