# 股票评价

## 功能
对输入的任意 A 股/港股/美股股票（支持代码或名称），进行多维度全方位分析，输出综合评价报告。所有数据均通过实时工具获取，并在报告中明确标注数据来源、更新时间及获取方式。

## 分析维度
1. **基本面分析**：PE、PB、ROE、营收增长率、净利润增长率、毛利率、负债率
2. **技术面分析**：近期趋势、成交量变化、支撑/阻力位、MACD/KDJ 信号
3. **行业与竞争分析**：所属行业景气度、行业排名、主要竞争对手对比
4. **资金面分析**：主力资金流向、北向资金、融资融券余额变化
5. **风险提示**：质押比例、商誉占比、大股东减持、监管风险
6. **综合评分**：按权重打分并给出投资建议（积极/谨慎/观望/回避）

## 使用方式
```text
@codey 帮我评价一下宁德时代（300750）
@codey 分析股票 600519
@codey 评价美股 AAPL
```

## 依赖工具
- **web_search** & **web_fetch**：获取实时行情、财务数据、新闻、资金流向等（必须实际调用，不得模拟）
- **scripts/evaluate_stock.py**：核心分析引擎，根据从工具获取的真实数据生成结构化报告

## 核心执行要求
1. 必须实际调用 web_search 和 web_fetch 工具获取实时数据，禁止使用模拟或假设数据。
2. 若因工具限制无法获取数据，必须在报告中如实声明，并明确标注“本项为基于现有数据的趋势推演，不构成事实”，同时说明工具不可用的可能原因（如“网络不可达、API调用未被授权、沙盒环境未启用网络请求等”）。
3. 所有数据表格下方必须注明真实来源、具体获取方式（含 URL 示例）和精确更新时间。
4. 工具调用失败时，自动尝试备用数据源（优先级：东方财富 → 同花顺 → Wind 公开页面），并记录备用源 URL。

## 执行流程
1. 接收用户输入的股票代码或名称。
2. 通过 `web_search` 和 `web_fetch` 依次获取各维度的实时数据（统一优先使用东方财富，数据缺失时使用同花顺或Wind等公开平台作为补充）。注意：构造正确 URL（A股深市：`https://quote.eastmoney.com/sz{代码}.html`，沪市：`https://quote.eastmoney.com/sh{代码}.html`，港股：`https://quote.eastmoney.com/hk{代码}.html`，美股：`https://quote.eastmoney.com/us{代码}.html`）。备用 URL 示例：同花顺 A 股行情 `https://www.10jqka.com.cn/` + 股票代码；Wind 数据可通过搜索获取。
3. 将获取的原始数据按维度整理后，通过代码块展示调用 `scripts/evaluate_stock.py` 的方式，例如：
   ```python
   python scripts/evaluate_stock.py --code 300750 --data '{"基本面": {...}, "技术面": {...}, ...}'
   ```
4. 输出最终 Markdown 报告，严格执行输出规范。

## 输出格式与数据真实性规范
- 分段输出 Markdown 报告，包含数据表格、评分卡。重要指标 **加粗**，风险项用 ⚠️ 标记。
- 每个数据表格下方注明：
  - **数据来源**：使用哪个工具从哪些平台获取（若启用备用源需注明）
  - **获取方式**：简要说明如何调用工具，给出具体 URL 示例
  - **更新时间**：精确到分钟（如“2025-05-20 15:00 实时”）或注明“日频/周频”，同时说明最近一次更新时间
- 若数据无法通过工具实时获取（如某些财务指标仅存在于年报），必须声明“该数据来自上一个完整财报周期，可能存在滞后”，并标注具体财报截止日期。**必须使用该标准措辞。**
- 技术面分析中的支撑/阻力位、技术指标数值必须明确标注是通过工具实际获取的实时数据，还是基于历史数据的推测。如果是推测，必须使用“假设”或“推测”或“可能”等措辞，并注明“本项为基于现有数据的趋势推演，不构成事实”。
- 对于假设性分析，需在结果中使用单独加粗段落（如 `⚠️ **免责声明：** 本项为基于现有数据的趋势推演，不构成事实。`）。
- 报告末尾增加数据说明：本报告所有数据均通过 @codey 的 web_search 和 web_fetch 工具实时采集，如有数据延迟或缺失，会明确说明。本报告仅供学习参考，不构成投资建议。

## 数据源统一规则
- **基本面**：优先从东方财富个股财务页面获取，示例 URL：`https://quote.eastmoney.com/f10/finance.html?code=300750`；备用：同花顺个股财务 `https://www.10jqka.com.cn/finance/`
- **技术面**：优先从东方财富实时行情页面获取，示例 URL：A股深市 `https://quote.eastmoney.com/sz300750.html`，沪市 `https://quote.eastmoney.com/sh600519.html`，港股 `https://quote.eastmoney.com/hk{代码}.html`，美股 `https://quote.eastmoney.com/us{代码}.html`；备用：同花顺行情页 `https://www.10jqka.com.cn/`
- **行业与竞争**：通过 web_search 搜索权威机构报告（如 SNE Research、IDC、公司官网），并用 web_fetch 抓取具体数值；同时参考东方财富行业板块数据。备用：搜索“股票代码 行业排名”
- **资金面**：优先从东方财富资金流向页面获取，同花顺大宗交易数据作为补充。示例 URL：`https://data.eastmoney.com/stock/hsgt/top10.html`（输入股票代码）
- **风险提示**：通过 web_search 搜索公司公告及新闻，用 web_fetch 验证具体信息。备用：搜索“股票代码 质押 减持 2025”
