# 收集高达相关网站大全

通过百度搜索收集所有高达相关网站（官方、模型、论坛、视频等），并分类整理输出

这是一个结构化 Workflow，请严格按以下节点顺序执行。每完成一个节点后确认输出符合预期再继续下一个节点。如果任何节点失败，停止并报告问题。

## 变量

- `{{topic}}`: 搜索主题关键词，如高达、Gundam (默认: 高达)

## 执行节点

### Node 1: 在百度上搜索多个维度的相关页面并提取搜索结果内容

- **目标**: 在百度上搜索多个维度的相关页面并提取搜索结果内容
- **工具**: browser_run
- **期望输出**: 多个搜索结果页面的文本内容，包含网站名称和链接信息
- **Token 预算**: 8000

### Node 2: 将上一步收集的搜索结果整理为分类清晰的高达网站大全列表

- **目标**: 将上一步收集的搜索结果整理为分类清晰的高达网站大全列表
- **工具**: 
- **期望输出**: 分类整理的高达网站列表，包括官方、模型、论坛、视频等类别
- **Token 预算**: 2000

## 执行规则

- 按节点顺序逐个执行，不要跳过
- 每个节点只使用该节点列出的工具
- 将变量 `{{...}}` 替换为用户提供的实际值（或使用默认值）
- 保持输出简洁，节约 token
