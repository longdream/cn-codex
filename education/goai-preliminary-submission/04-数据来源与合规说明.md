# 数据来源与合规说明

> 对应 GOAI 手册：初赛建议说明，复赛必交。  
> 本项目定位为 **AI+教育辅助系统**，不替代教师、学校或专业机构最终判断。

---

## 1. 合规原则总览

1. **最小必要**：只采集完成学习支持所需数据  
2. **目的限定**：数据仅用于规划、陪伴、反馈分析与成长回顾  
3. **授权优先**：未成年人相关能力按功能分级取得监护人/学生授权  
4. **可解释可修正**：关键状态可见来源、时间窗与更正入口  
5. **可撤回可删除**：支持授权撤回、导出与删除请求  
6. **边界清晰**：辅助建议 ≠ 正式教育评价 / 心理诊断 / 医疗意见  
7. **本地优先**：默认以本机/受控环境存储为主，减少不必要上传  
8. **心理学友好采集**：支持性收集，非评估审讯；保护自主感、能力感、关联感  
9. **纸质优先与屏时克制**：主学习离屏；作业照片最小必要、可删

## 2. 数据类型与来源

| 数据类型 | 来源 | 是否含个人敏感信息 | 授权要求 | 处理方式 | 使用边界 |
|---|---|---|---|---|---|
| 基础学习档案 | 学生主动填写（年级、学科、目标、可学习时间） | 可能含未成年人一般个人信息 | 使用同意 + 未成年人监护人同意（按法规与产品策略） | 结构化存储；可编辑 | 仅用于个性化计划 |
| 任务与计划数据 | 系统生成 + 学生确认 | 一般 | 同上 | 事件化记录 | 学习编排 |
| 交互事件 | 弹窗提交、开始/暂停/改期等 | 一般 | 产品使用授权 | 本地事件账本 | 状态机与学情 |
| 学习反馈 | 完成情况、难点、难度、信心自评 | 一般/主观感受 | 可跳过项需明示 | 绑定任务 scope 与有效期 | 不得用于人格标签 |
| 线下学习反馈 | 学生主动反馈；可选作业局部图 | 附件可能含间接标识 | 附件单独授权；默认可不传 | 脱敏提醒；可选压缩 | 仅错因/完成证据 |
| 语音（可选） | 学生主动录音 | 可能含声纹等生物特征风险 | 显式开启；可关 | **只做转写**；原始音频最短必要后删除 | 禁止副语言/情绪声学分析 |
| 学习姿态类别（可选） | 手机摄像头授权采样 | 图像本身敏感；落库仅为类别 | **默认关**；未成年人监护人+学生；可随时关 | **端侧优先**；默认只存类别/时间/置信度，不存原视频与人脸模板 | 仅用于温和提醒/任务粒度建议；禁止惩罚、告状、身份识别、情绪诊断 |
| 学科知识资源 | 内置官方学科包（JSON） | 否 | 产品内置 | 结构化知识/模板/错因 | 非完整教材非法分发 |
| 学习材料清单 | 学生/监护人申报；可选封面拍照 | 一般 | 功能授权 | 材料档案；可编辑删除 | 页码任务与缺口建议 |
| 作业/错题照片 | 学生主动拍摄 | 可能含姓名/校名 | 单次或功能授权；可拒 | OCR 后优先结构化；原图可删 | 仅诊断；禁止监控连拍 |
| 掌握证据 | 作业照片、自批/师批、难点反馈、材料进度 | 一般 | 学习支持授权 | 分层写入 evidence/mastery | 完成≠掌握；可更正 |
| 学科脚手架 | 知识图谱与错因模板 | 否 | 产品内置 | 归类卡点与策略 | 非内置刷题题库 |
| Demo/评测数据 | 自建模拟学生“小林”等 | 否（虚构） | 不适用 | 标注为模拟 | 演示与测试 |
| 模型调用日志 | 本地/服务配置 | 可能含提示片段 | 最小化；可配置脱敏 | 按需保留排障信息 | 禁止用于无关画像 |

### 明确不采集 / 不处理

- 身份人脸识别、人脸特征模板、面部微表情“情绪读心”  
- 眼动追踪、无授权的持续环境录音/录像与监控式常开摄像头  
- 将学习姿态用于惩罚、排名、告状或心理疾病诊断  
- 声纹识别、语速音调等副语言情绪推断  
- 键盘节律、后台偷窥式停留监控用于情绪判定  
- 未授权的学校官方成绩库、学籍敏感库、他人作业  
- 用于排名、惩罚或商业画像转售的数据用途  
- 完整商业题库/教材扫描分发；无出处黑箱题库  
- 以系统题库要求学生长时间屏上作答  
- 作业照片用于惩罚、排名或未授权分享  

> 允许项（严格边界）：学生主动开启的**学习姿态类别辅助**——端侧优先、默认不存原视频、短有效期、可随时关闭。

## 2.1 心理学友好采集方式（防被动/反感）

孪生数据质量取决于学生是否愿意真实分享。本项目把采集定义为**支持性收集**，并写入合规与产品双重约束：

| 原则 | 要求 | 禁止 |
|---|---|---|
| 自主感 | 可跳过、可稍后、可关某项采集 | 强制长问卷门禁 |
| 能力感 | 成长语言、策略选项、不贴人格标签 | “差/懒/态度不好”等评价 |
| 关联感 | “一起安排”口吻，共同决策 | “系统命令你汇报” |
| 透明 | 问前说明用途，画像可见可改 | 黑箱用途 |
| 低负荷 | 一次一问，优先选择题 | 连珠炮、超长表 |
| 可撤回 | 更正、过期、删除 | 跳过=差评 |

**数据处理含义**：

- `skip` / `later` 只记录“未提供”，**不得**推断负面动机或能力  
- 学生更正事件优先于旧推断  
- 话术模板需过禁用词表，方可进入生产配置  
- 敏感通道（姿态/语音）默认关，开启使用邀请句而非监控句  

### 2.2 学科内容出处与掌握证据（可追溯）

| 问题 | 本项目答案 |
|---|---|
| 题目从哪来 | **学生已有纸质卷子/教辅/学校作业**（主）；系统 demo 仅兜底 |
| 答案从哪来 | 材料答案页 / 教师批改 / 学生自批；AI 辅助诊断并标置信度 |
| 学生怎么学/输入 | **纸笔离屏主学**；短时沟通确认；手机拍照或反馈回传 |
| 解析从哪来 | 先问卡点 + 错因策略模板 + 可选分步讲解；提示查阅材料解析 |
| 如何知掌握 | 作业照片与错因趋势 + 材料进度 + 自批/师批；完成≠掌握 |
| 是否长时间盯屏 | **否**；屏幕仅短时教练会话 |

## 3. 模拟数据说明（初赛/Demo）

初赛与演示优先使用**模拟数据**，避免真实未成年人数据风险。

| 字段 | 示例 | 含义 |
|---|---|---|
| student_id | stu_demo_lin | 虚构学生 |
| grade | 8 | 初二 |
| goal | 半年内数学提升 20 分 | 演示目标（不承诺提分结果） |
| subject | math | 初中数学包 |
| tasks | 函数图像映射等 3 个样例 | 真实场景风格的模拟任务 |
| feedback | 图像与解析式转换困难 | 用于触发干预策略演示 |

**模拟逻辑**：按预置脚本走完“友好沟通→材料盘点→纸质页码任务→离屏完成→拍照/反馈→错因诊断→掌握证据→动态计划确认→周回顾”。  
**适用范围**：方案演示、交互走查、工程联调；不代表真实教学效果统计。

## 4. 授权与同意模型

### 4.1 分级授权

| 能力 | 默认 | 授权主体 | 可撤回 |
|---|---|---|---|
| 基础目标/计划 | 需使用同意 | 学生；未成年人+监护人策略 | 是（影响服务完整性） |
| 学习状态自评采集 | 功能级同意 | 学生（可跳过单次） | 是 |
| 主动提醒 | 偏好设置 | 学生 | 是（静默/免打扰） |
| 语音输入 | 默认关 | 学生显式开；未成年人加强提示 | 是 |
| 作业图片附件 | 默认不要求 | 单次或功能授权 | 是 |
| 家长周报 | 默认最小摘要 | 监护人+学生知情 | 是 |
| 教师聚合视图 | 默认关 | 明确授权范围 | 是 |
| 学习姿态辅助 | **默认关** | 学生显式开；未成年人+监护人 | 是（立即停止采样） |

### 4.2 私密对话边界

- 家长/教师**默认不可**查看学生私密对话全文  
- 可共享：任务完成概况、经授权的学情摘要、安全风险必要提示  
- 任何扩大共享范围需额外确认  

### 4.3 撤回与删除

撤回后：

1. 停止新的对应数据采集与处理  
2. 删除或匿名化授权范围内可删除数据（法律要求保留的最小审计除外）  
3. 取消未完成的相关 `orchestration_job`  
4. 记录 `consent_withdrawn` 审计事件

## 5. 隐私保护技术措施

| 措施 | 说明 |
|---|---|
| 最小化字段 | 反馈表单可跳过非必要项 |
| 有效期 | 精力/任务感受等动态状态自动过期 |
| 范围隔离 | 状态按学科/目标/任务 scope，禁止跨学科人格总分 |
| 推断隔离 | 系统推断默认非正式状态，需规则约束 |
| 访问控制 | 角色权限隔离；管理员不可任意浏览内容 |
| 语音处理 | 转写后删原音频；Agent 只读最终确认文本 |
| 附件 | 上传前提示去除姓名/校名等；可只描述不上传 |
| 传输与存储 | 优先本地；若使用云模型 API，按最小必要上下文注入摘要而非全量账本 |
| 审计 | 授权、删除、导出、高风险阻断可追溯 |

### 5.1 手机姿态通道专项

| 要求 | 说明 |
|---|---|
| 目的限定 | 仅服务学习坐姿/距离提醒与任务粒度建议 |
| 数据形态 | `category + time + confidence`，不是人脸 embedding |
| 保留策略 | 默认 `raw_media_retained=false` |
| 学生控制 | 忽略单次提醒 / 关闭能力 / 删除历史姿态记录 |
| 与孪生关系 | 短效线索，覆盖度有限；不得单独决定高影响计划 |

## 6. 行业边界与风险提示（教育）

依据 GOAI 手册 AI+教育边界与通用行业边界：

1. **不得替代**教师教学判断、学校评价、考试结果或专业教育服务  
2. **不建议**以直接给出标准答案作为主产品路径；鼓励提示、追问、分步讲解、错因与同类练习  
3. **不得**输出心理疾病诊断、治疗方案或危机干预替代结论  
4. 遇可能的自伤/他伤等高风险表述：停止常规学习编排，提示联系现实中可信成人或专业渠道  
5. 计划与提分相关表述必须避免“保证提分”；仅提供可执行学习支持  
6. 所有干预建议应展示依据，并允许学生拒绝/改期/保持原计划  

产品内固定提示语（示例）：

> 本系统提供学习辅助建议，不能替代老师、学校或专业人士的判断。重要决定请与老师/家长确认。

## 9. 数据流简图

```text
学生输入 / 时钟触发 / 线下反馈
  → 授权检查（L0）
  → 事件落库（本地教育账本）
  → L1 规则/模板 或 L2 模型编排（仅摘要上下文）
  → 结果以“建议+选项”交付
  → 学生确认后写回计划/孪生高影响字段
  → 审计与可导出记录
```

禁止路径：

```text
摄像头/生物特征 → 情绪标签 → 自动惩罚/告密
未授权全文对话 → 家长默认可见
全量 evidence_ledger → 直接塞进模型 prompt
```
