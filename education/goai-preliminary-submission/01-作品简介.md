# 作品简介

**项目名称**：AI 自主学习教练系统（AI Learning Coach）  
**所选赛题**：AI+教育  
**目标用户**：初中自学学生（主用户），授权范围内的家长/监护人与教师（辅助视图）

**核心问题**：计划僵硬、反馈空泛；很多 AI 教育又把学生按在屏幕前刷内置题库，既伤眼又与真实卷子脱节。

**解决方案**：**纸质主学、短时屏幕教练**。用心理学友好沟通了解学情与已有卷子/教辅，建议今晚练哪几页、是否还需补材料（可拒）；学生离屏纸笔完成，再用手机短时拍照错题或反馈。AI 做错因与计划调整，不直接给答案，不把孩子绑在题库 App 上。数字孪生记录材料进度与掌握证据，计划动态可协商。

**创新点**：
1. 纸质优先：真实卷子/作业主战场，屏时克制；
2. 材料盘点 + 可选购书建议（顾问而非商城）；
3. 拍照/反馈取证 → 掌握证据 → 动态计划；
4. 友好采集与会生长数字孪生。

**开放/复用价值**：材料盘点与作业证据协议、孪生契约、错因脚手架可复用。

**项目进展**：已完成需求设计、教学引擎、产品技术规格与项目方案，并持续推进交互原型和工程实现。
