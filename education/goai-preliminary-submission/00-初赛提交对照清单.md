| 材料 | 必交 | 形式 | 本包对应 | 提交动作 |

| 作品简介 | 是 | 文字 ≤500 字 | `01-作品简介.md` | 复制到官网简介栏 |

## D. 评审维度自检

| 维度 | 权重 | 本项目证据位置 |
|---|---|---|
| 行业场景价值 | 25% | 方案书 §1–2；一页纸 |
| Agent 能力与任务闭环 | 25% | 方案书 §2A/2B/3（含§3.4 学科闭环）/5；Agent 清单；SPEC §8 |
| 产品体验与 Demo 完成度 | 20% | 方案书 §4；Demo 清单（待补视频） |
| 技术实现深度 | 15% | SPEC + 架构说明 |
| 安全合规与可追溯 | 10% | 合规说明（含姿态边界）+ SPEC 安全验收 |
| 开放/复用贡献 | 5% | 方案书 §9；学科包/协议复用计划 |

## E. 上传前最后检查

1. [ ] 队伍名称、成员信息已填入一页纸与方案封面  
2. [ ] 作品简介字数 ≤500  
3. [ ] 方案已导出 PDF（建议 10–15 页）  
4. [ ] 无真实未成年人隐私、无密钥、无未授权数据  
5. [ ] 明确写了：辅助定位、不替代教师评价、模拟数据  
5b. [ ] 明确强调：孪生会生长、动态计划、姿态可选与合规边界  
5c. [ ] 明确强调：**心理学友好采集**（自主/可跳过/非测评话术/跳过不写负向）  
5d. [ ] 明确说清：题目/答案/解析来源与知识点掌握证据渠道  
5e. [ ] 明确：**纸质主学**、材料盘点、拍照取证；**非内置题库长时间刷屏**  
6. [ ] （可选）Demo 视频/截图已放入 assets 或提供链接  
7. [ ] 官网意向赛道勾选 **AI+教育**
