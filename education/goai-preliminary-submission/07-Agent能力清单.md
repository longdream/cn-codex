# Agent 应用能力清单

| 字段 | 填写内容 |
|---|---|
| 应用入口 | **中国 Codex 教育版**桌面应用：任务列表与教学引擎入口；到点主动提醒；手机端可选「姿态辅助」入口（共享同一孪生） |
| 目标用户 | 主用户：初中及以上所有想主动学习的学员（初中/高中/大学及成人自学者）；辅助：授权范围内的家长/监护人、教师/辅导者 |
| 核心流程 | 友好沟通 → **材料盘点** → 纸质页码任务 → 离屏完成 → **拍照/反馈取证** → 错因诊断 → 动态计划确认 → 周期回顾 |
| Agent 能力 | 友好采集；材料盘点与建议；纸质任务编排；作业照片诊断；**态度精神 + 知识掌握双维孪生**；掌握证据；动态计划；屏时克制；安全合规 |
| 工具 / 系统依赖 | 大模型（可插拔）；本地规则/模板；学科包；事件账本与孪生存储；可选语音转写；可选手机端姿态估计；自研 Agent 运行时 |
| 输入 | 目标与时间偏好；弹窗作答；线下反馈；可选语音文本；可选姿态类别事件；时钟时间窗 |
| 学科内容 IO | 题目←学生已有纸质材料；答案←答案页/师批/自批+AI 辅助；解析←策略/错因；掌握←拍照与反馈证据 |
| 屏时策略 | 屏幕短时沟通与回传；正式解题离屏；禁止内置题库连刷主路径 |
| 输入采集方式 | 支持性收集：用途说明 + 单题 + 可跳过/可更正；禁用测评羞辱话术 |
| 输出 | 生长中的孪生摘要；动态计划与调整建议；主动询问；教学引导；错因/策略；姿态温和提醒；成长回顾；边界提示 |
| 失败处理 | 覆盖度不足：轻问/保持计划；姿态误检：可忽略可关；L2 超时降级 L1；高风险阻断并转介；未授权拒绝采集 |
| 安全边界 | 不替代教师评价；不做心理诊断；**采集不评估审讯**；跳过≠差评；姿态默认关且不惩罚；高影响改计划须确认 |
| 运行证据 | 可运行桌面端（`cn-codex-edu`，`pnpm dev`：建档→页码任务→LLM 教练对话→成长面板）；vitest 测试（教育 store、姿态/试卷筛选）；HTML 原型 6 屏 + 截图；方案/SPEC/合规文档；视频待录制 |

## 子 Agent 能力分解

| Agent | 能力点 | 典型触发 | 输出形态 |
|---|---|---|---|
| Supervisor | 路由、预算、汇总解释 | 任意学习事件 | 行动计划 / job |
| Planning | 目标拆解、周计划、滚动调整 | 初始化、周回顾、重排请求 | 计划与任务 |
| Companion | 主动启动、反馈采集、温度话术 | 时间窗、任务结束 | Modal / 消息模板 |
| Companion | **友好采集话术**、跳过出口、用途说明 | 冷启动/反馈节点 | 支持性模板 |
| Companion | 姿态温和提醒（可忽略） | 授权下的姿态事件 | 提醒卡 / 缩时选项 |
| Growth Analysis | 证据关联、趋势、置信度 | 反馈、连续困难 | 洞察卡 |
| Intervention / Planning | **动态计划**选项与影响说明 | 洞察命中、节奏偏离 | 可确认建议 |
| Safety | 过滤、频控、升级 | 敏感内容、越权 | 阻断/提示 |

## 与“非 Agent 产品”的区分

| 非目标形态 | 本系统对应能力 |
|---|---|
| 泛聊天机器人 | 有状态任务机 + 结构化交互 + 计划写回 |
| 单轮问答 | 多轮主链路 checkpoint |
| 纯内容生成 | 生成后需确认，且服务学习证据闭环 |
| 静态 PPT 概念 | 可演示输入→处理→工具/知识→交付→验证 |
