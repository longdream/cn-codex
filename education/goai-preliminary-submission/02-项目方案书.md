## 1. 场景来源与行业价值

### 1.1 为什么做 AI+教育 Agent

GOAI AI+教育赛题鼓励：个性化学习规划、作业辅导、学情诊断、教师备课、学习陪伴；强调**因材施教、任务闭环、教学友好与未成年人数据合规**。  
不鼓励：简单题库问答、标准答案生成器、无流程泛聊天。

真实课堂与自学现场常见断裂：

1. **目标难落地**：学生有“想提分”的愿望，但缺少可执行的阶段路径与每日任务。
2. **启动难持续**：知道要学，却在时间窗内难以开始；工具只会催促，不会协商。
3. **线下学习不可见**：纸质作业、教材阅读、试卷训练发生在 App 外，系统无法理解困难。
4. **受挫支持失当**：要么直接给答案，要么只给鸡汤，缺少错因分析与策略脚手架。
5. **计划不会生长**：静态计划无法随证据、信心与节奏变化而调整。
6. **状态采集难**：真实学情分散在聊天、作业、情绪与身体姿态中，一次问卷或刷题日志远不够支撑“因材施教”。

### 1.2 目标用户与价值

| 用户 | 痛点 | 价值收益 |
|---|---|---|
| 学生 | 不会规划、难启动、线下困难说不清 | 可执行计划、主动但不打扰的陪伴、策略支持、看见成长 |
| 家长/监护人（授权） | 想了解支持是否有效，又怕过度监控 | 周报与风险提示，默认不看私密对话全文 |
| 教师/辅导者（授权） | 难以及时发现需帮助的学生 | 聚合学情与可操作线索，最终判断仍由人作出 |

### 1.3 赛题映射

| 赛题方向 | 本项目对应能力 |
|---|---|
| 个性化学习规划 | 目标确认 + 阶段/周计划 + 滚动调整 |
| 作业辅导 | 分步提示、错因分析、换表征，不直接给答案 |
| 学情诊断 | **会生长的数字孪生** + 多源证据账本 + 可解释洞察 |
| 计划个性化 | **动态计划**随孪生状态滚动，而非一次性课表 |
| 学习陪伴 | 授权时间窗主动启动、结构化反馈、周期回顾 |
| 教学友好 | Modal-first 交互、可拒绝建议、逐步放手 |
| 合规 | 最小化采集、监护人授权、可删可导出、不替代正式评价 |

## 2. 问题定义与产品定位

### 2.1 问题陈述

> 如何让 AI 像优秀教师一样**长期理解学生、主动陪伴、连接真实线下学习，并在边界内动态调整支持**，同时逐步把自主学习能力交还学生？

### 2.2 产品定义

**AI 自主学习教练系统**是长期学习支持系统，而非答题工具、陪读聊天或打卡器。

核心理念：

> 从“教师/系统管理学生学习”，转变为“AI 帮助学生形成自主学习能力”。

### 2.3 评委 10 秒记忆点

```text
不是等学生提问，而是理解学生后主动陪伴。
不是一次问卷档案，而是多次交流中生长的数字孪生。
不是死板课表，而是孪生驱动的动态可协商计划。
不是内置题库刷屏，而是用学生**已有纸质卷子/作业**作主战场。
屏幕只做短时沟通、材料建议与拍照复盘，把护眼与专注还给纸笔。
```

### 2.4 非目标（边界）

- 不提供心理疾病诊断、治疗或危机干预替代服务  
- 不代替学校正式评价、升学决策或教师专业判断  
- 不对学生进行自动化惩罚、排名或人格标签化  
- 不做“情绪读心”式面部微表情/人格推断；姿态能力仅服务学习支持且可关  
- 不用高频催促与焦虑话术驱动学习  
- **不以系统内置题库作为长时间屏上作答主路径**  
- 不替代家长/教师决定是否购书；材料建议可拒绝

## 2A. 核心特色一：会生长的学生数字孪生

### 2A.1 为什么“数字孪生”是特色，而不是换皮档案

**关键判断**：没有对学生状态的持续、可解释把握，就做不好个性化反馈，更做不好计划调整。  
数字孪生不是把学生做成固定标签，而是把**多次交流与多源证据**沉淀为可更新的成长模型。

```text
多轮对话 · 任务行为 · 结构化反馈 · 线下作业 · 可选姿态信号
        ↓ 分层写入（事实 / 自评 / 推断）
     学生数字孪生（持续生长）
        ↓
  有依据的反馈  +  动态计划调整（学生确认）
```

### 2A.2 学情采集有多难：常见做法 vs 本系统

| 维度 | 传统/常见做法 | 采集难度与问题 | 本系统数字孪生怎么处理 |
|---|---|---|---|
| 建档方式 | 一次问卷、入学测评、静态标签 | 学生觉得“被考试/被打分”；结果很快过期；易贴“差生/懒”标签 | **对话式多次短问 + 可编辑确认**；禁止人格标签化 |
| 时间维度 | 以周/月考试点为切片 | 日常波动、启动困难、临场受挫看不见 | **时间序列状态**（有效期、趋势、覆盖度） |
| 数据来源 | 多为 App 内刷题对错 | 线下作业、真实困难、身体疲劳几乎缺失 | **多源证据账本**：对话、任务、线下反馈、可选姿态 |
| 状态语义 | 完成率、正确率当“学情” | 完成≠掌握；未完成≠不努力；易引发羞耻 | **事实/自评/推断分层**；完成与掌握解耦 |
| 学生控制权 | 画像黑箱，学生难纠正 | 错画像长期误导；对抗与假回答 | **可见、可解释、可更正、可跳过、可关采集** |
| 隐私成本 | 要么不采，要么过度监控 | 摄像头滥用引发不信任与合规风险 | **分级授权、默认最小、姿态可关、本地优先** |
| 服务用途 | 报表给成人看 | 对学生当下行动帮助弱 | **直接服务学生**：驱动反馈话术与可协商计划 |
| **心理感受** | 评估式、监控式、催促式 | 被动、反感、防御性回答 | **支持性收集**：自主、能力、关联三感优先 |

### 2A.3 心理学友好采集原则（核心特色 · 必讲）

> **主张**：数字孪生不是“越采越多越好”，而是**学生愿意持续、真实地分享**才有价值。  
> 若采集方式让学生感到被测评、被监控、被贴标签，孪生会迅速失真——假数据比没数据更危险。

本系统将孪生信息收集设计为**支持性收集（supportive elicitation）**，而不是**评估式审讯（evaluative interrogation）**，对齐自主决定理论（SDT）与教育心理中的安全、透明、可控原则：

| 原则 | 心理学含义 | 产品落点 | 反模式（禁止） |
|---|---|---|---|
| **自主感 Autonomy** | 我能决定分享什么、何时分享 | 每题可跳过/稍后；高影响动作须学生确认；可关某项采集 | 强制填完才能用；默认开启摄像头 |
| **能力感 Competence** | 分享不会让我显得“差” | 用成长语言；选项中性/正向；错因谈策略不谈人格 | “你是不是很差/很懒”；完成率羞辱 |
| **关联感 Relatedness** | 这是一起把学习变好，不是审查 | “我们一起看看…”；共同决策下一步 | “系统要求你汇报” |
| **低认知负荷** | 短问、少问、好答 | 每次 1 个主问题；优先 choice 弹窗；3–5 轮冷启动 | 一页 20 题长问卷 |
| **透明目的** | 知道为什么问、怎么用 | 问前一句用途说明；画像可见可改 | 黑箱采集、用途模糊 |
| **非评估框架** | 不是考试、不是鉴定 | 避免“测评/诊断/评级”措辞；用“了解近况/一起安排” | 入学测评口吻、能力打分 |
| **正向与微承诺** | 小步同意，降低防御 | 先问目标愿望，再问时间；先给选择再问细节 | 一上来薄弱点清单逼供 |
| **可撤回信任** | 说错了能改，不想说可以不说 | 更正入口、过期失效、跳过不写负向默认 | 跳过=差评；错了改不了 |

**语言框架对照（暗示与措辞）**：

| 场景 | 易引发被动/反感 | 心理学友好说法（本系统默认） |
|---|---|---|
| 冷启动 | “请完成学情测评问卷” | “我想先听听你希望半年后哪里更轻松一点——随时可以说‘先不聊这个’” |
| 目标 | “你的薄弱学科是？” | “如果只挑一件最想先变好的事，你会选哪一件？” |
| 时间 | “每天必须学习多久？” | “这周里，哪些时间段你比较容易安安静静学一会儿？” |
| 反馈 | “为什么又没完成？” | “今天卡在哪一步了？我们可以一起换个更轻的安排” |
| 精力 | “你是不是状态差？” | “现在更像‘还能冲一把’还是‘想短一点’？” |
| 姿态 | “摄像头将监控你的坐姿” | “如果你愿意，手机可以轻轻提醒坐姿舒不舒服——随时能关，也不会告诉别人” |
| 更正 | “系统判断你学习态度不佳” | “如果我觉得理解得不准，你可以直接改；改了之后计划会跟着你” |

**采集节奏（防反感）**：

1. **先关系后数据**：先说明“帮你安排得更合适”，再提问。  
2. **先选择后填写**：优先单选/多选，少逼长文。  
3. **一次一事**：单轮只推进一个主问题，避免连珠炮。  
4. **随时出口**：跳过 / 稍后 / 今天先到这 / 关掉此类询问。  
5. **即时回报**：学生答完立刻看到“这对计划意味着什么”，避免只采不用。  
6. **沉默也是数据**：跳过 ≠ 负面标签；只记“未提供”，不推断人格。

### 2A.4 “多次交流生长”机制（心理学友好版）

孪生不是初始化后冻结，而是在**学生愿意继续聊**时自然生长：

1. **冷启动（建立安全）**  
   - 用愿望与时间打开，不先做“能力鉴定”  
   - 3–5 轮短对话 + 1 次摘要确认即可形成最小孪生  
   - 覆盖度低时明确说：“我现在还只了解一点点，后面再慢慢补”  
2. **日常生长（嵌入任务，不额外考试）**  
   - 在启动、结束、改期等自然节点用 1 个轻问采集  
   - 话术保持中性温暖，并始终给选择权  
3. **冲突修正（保护面子）**  
   - 学生说“这不准确” → `student_correction`，旧结论 supersede  
   - 系统致谢修正，不争辩对错  
4. **过期回落（避免永久标签）**  
   - 精力、任务感受等短效状态到期失效  
5. **覆盖度诚实（不懂时装懂是事故）**  
   - 证据不足时只轻问或保持骨架计划，不武断重排  

> 评委记忆点：**孪生越用越懂，但永远可纠正；学生越觉得被尊重，越愿意给真实信息。**

### 2A.5 只有孪生在，反馈和调计划才站得住

| 若没有数字孪生 | 系统只能… | 后果 |
|---|---|---|
| 无连续状态 | 按固定脚本催学/推题 | 打扰且无效 |
| 无证据账本 | 凭单次对错给建议 | 误判、伤害信心 |
| 无学生确认层 | 自动改计划 | 失控感、对抗 |
| 有孪生 + 友好采集 | 看见“图像转换连续受阻 + 今晚想短一点” | 建议缩短映射练习，学生可接受/改期 |

**结论（产品主张）**：  
**数字孪生是反馈质量与计划弹性的前提**；**心理学友好采集是孪生数据可信的前提**。  
Agent 负责行动，孪生负责“理解得对不对”，友好采集负责“学生愿不愿说实话”。

## 2B. 核心特色二：动态计划 vs 传统学习计划

### 2B.1 对比总表

| 对比项 | 传统学习计划 | 本系统动态计划 |
|---|---|---|
| 生成方式 | 开学/周末一次排满 | 目标确认后生成骨架，**随证据滚动** |
| 调整触发 | 家长/老师主观改，或考砸后大改 | 任务反馈、连续困难、节奏偏离、姿态/精力信号、周回顾 |
| 调整粒度 | 常整周推倒重来 | 任务级：降阶、缩时、换策略、改期、缓冲 |
| 是否协商 | 多为“按表执行” | **每项高影响调整需学生确认**（可拒绝） |
| 状态感知 | 弱（完成勾选） | 强（孪生五维 + 证据） |
| 失败语义 | 未完成=没毅力 | 先理解原因：难/累/时间窗不现实/策略不对 |
| 输出形态 | 静态课表/打卡表 | 可执行任务 + 依据说明 + 备选路径 |
| 长期目标 | 易与日常脱节 | 阶段路线与每日任务双向对齐 |

### 2B.2 动态计划如何“不死板”

```text
传统：  目标 → 一次性周计划 → 打卡 → （失败）责备或放弃
本系统：目标 → 骨架计划 → 执行证据进入孪生
           → 洞察（为何卡）→ 可选调整 → 学生确认
           → 新任务写回 → 计划继续生长
```

不死板的三条硬规则：

1. **计划是假设，证据是裁判**：连续同类错因时优先换表征/降阶，而不是加量硬推。  
2. **学生有否决权**：系统提出“建议”，不偷偷改已确认计划。  
3. **留白是功能**：首周默认缓冲；允许暂停、缩短到 10 分钟起步，而不是排满制造焦虑。  

### 2B.3 孪生 × 动态计划的耦合（特色闭环）

```text
                ┌──────────────────┐
                │ 学生数字孪生      │
                │ (多次交流生长)    │
                └────────┬─────────┘
           状态/证据/置信度│
        ┌────────────────┼────────────────┐
        ▼                ▼                ▼
   反馈怎么说       下一步练什么       计划怎么改
  （陪伴 Agent）   （教学主链路）    （规划/干预 Agent）
        │                │                │
        └──────────── 学生确认 ───────────┘
                         │
                         ▼
                   计划与孪生回写
```

没有左上角的孪生，右侧三个动作都会退化成模板话术或死板课表。

## 2C. 核心特色三：手机端学习姿态感知（可选增强）

### 2C.1 要解决什么

自学场景中，状态不只存在于“会不会做题”，也存在于**是否长时间趴桌、过度前倾、离屏过近、频繁离座**等可观察学习姿态。这些信号若完全忽略，孪生对“投入/疲劳/环境是否适合继续”会偏盲；若滥用摄像头做监控与惩罚，则不可接受。

### 2C.2 能力定义（产品口径）

| 项 | 说明 |
|---|---|
| 入口 | 手机端（或平板）在学习任务进行中，**学生主动开启**“学习姿态辅助” |
| 感知目标 | 学习相关姿态/距离类别：如坐姿端正、明显趴伏、过度前倾、疑似过近、长时间静止后需活动提醒等 |
| 不感知 | 人脸识别身份、面部微表情情绪、颜值、身份核验、教室监控式持续录像回传 |
| 输出用途 | 写入孪生的**低打扰、短有效期**状态线索；触发温和提醒或任务粒度建议（休息/改坐姿/缩短任务） |
| 非用途 | 不用于打分排名、不自动告状、不作为惩罚依据、不替代健康医疗判断 |

### 2C.3 处理流程

```text
学生授权开启姿态辅助
  → 手机摄像头本地预览/周期采样（可配置）
  → 端侧或受控环境估计姿态类别（非身份识别）
  → 仅上传/落库“姿态类别 + 时间 + 置信度”（默认不存原视频）
  → 孪生短效观测（如 30–120 分钟有效）
  → Companion/Intervention：提醒坐姿、建议休息、缩短任务等可选项
  → 学生可一键忽略 / 关闭姿态辅助
```

### 2C.4 与数字孪生、动态计划的关系

| 姿态信号（示例） | 孪生理解（谨慎表述） | 可能的动态调整 |
|---|---|---|
| 多次明显趴伏 | 当前学习姿势可能不适，证据有限 | 提醒调整坐姿；建议 2 分钟活动 |
| 过近屏幕 | 距离可能不适合长时间学习 | 提示后移设备；可选缩短本段任务 |
| 长时间高负荷姿态 + 自评累 | 支持强度可能偏高 | 建议降阶/改期，学生确认 |
| 关闭授权 | 无姿态通道 | 回退到对话与任务反馈主路径 |

> 姿态是**增强通道**，不是孪生的唯一真相。主路径仍是交流、任务与线下反馈。

### 2C.5 合规与信任设计（必须写清）

1. **默认关闭**；首次使用显著告知目的、采样方式、是否保存图像。  
2. **未成年人**：监护人授权 + 学生知情；可随时关闭。  
3. **最小化**：默认只存结构化姿态标签，不存人脸特征模板，不上传原视频（除非用户明确导出调试且可删）。  
4. **本地优先**：能在端侧完成的推理优先端侧。  
5. **可拒绝**：提醒可忽略；绝不因姿态自动记过或通知家长惩罚。  
6. **边界声明**：姿态辅助≠健康诊疗；持续不适请寻求现实支持。

## 3. 核心用户流程（任务闭环）

### 3.1 主闭环（必须可演示）

```text
友好沟通建档（可跳过项）
  → 学习材料盘点（已有卷子/教辅/学校作业；缺什么）
  → 生成骨架计划：优先用现有纸质材料的页码/章节任务
  → 到点短时询问是否开始（可稍后/暂停）
  → **离屏纸笔完成**今日纸质任务
  → 手机短时回传：拍照作业/错题 或 结构化反馈
  → 数字孪生更新（事实 / 自评 / 推断分层）
  → 动态计划建议（继续订正 / 换页 / 是否补材料，学生确认）
  → 周期回顾
```

### 3.2 Demo 主场景：从线下作业到动态调整

**角色**：初二学生小林；目标“半年内数学提升 20 分”。

1. 自然对话识别目标、时间、薄弱点与偏好；学生确认画像摘要。  
2. **材料盘点**：已有学校练习册与教辅；AI 建议先用现有材料，不急着买新卷。  
3. 规划 Agent 生成骨架路线，并把“今晚任务”落到**练习册具体页码**（约 30–40 分钟纸笔）。  
4. 晚 20:00 短时弹窗：`开始 / 稍后 / 改期 / 暂停`——确认后**离开屏幕写作业**。  
5. 完成后手机拍 2–3 道错题 + 友好提问：“哪一步最卡？”（可跳过）。  
6. 成长分析归类错因；**不直接给整页答案**，给策略提示与明日订正范围。  
7. 动态计划建议明日页码/题量；学生确认后写回。  
8. 周末回顾：先听小林看法，再看证据；讨论是否需要补一本专项（可选、可拒）。  
9. （可选）纸质学习中若开启姿态辅助：长时间趴伏仅温和提醒是否休息/缩时，不惩罚。

### 3.3 教学执行层（任务内闭环）

```text
材料确认 → 今日纸质任务说明 → 离屏练习 → 拍照/反馈 → 错因与策略 → 明日协商 → 反思
```
屏幕侧仅用 **短时 Education Modal** 做确认与反馈采集；**正式解题在纸上**。对话区承载鼓励、错因叙事与计划说明，不鼓励长时间屏上刷题。

### 3.4 学科内容闭环（知识点 · 题目 · 答案 · 输入 · 解析 · 掌握）

> 产品立场更新：**学习主战场在纸质**；电子屏只承担短时沟通、材料盘点、计划确认与拍照复盘。  
> 评委常问：题从哪来？学生怎么学？系统怎么知道掌握？答案/解析从哪来？——本节按**纸质优先**回答。

#### 3.4.0 为什么不用“内置题库长时间屏上刷题”

| 方案 | 优点 | 风险 | 本项目取舍 |
|---|---|---|---|
| A. 系统内置题库屏上作答 | 数据好采、交互可控 | 长时间盯屏；与学校卷子脱节；易变成刷题 App | **非主路径**（仅极短 Demo/说明可用） |
| B. 只聊天不管作业 | 屏时短 | 学情虚、计划空 | 否 |
| C. **纸质主学 + 材料盘点 + 拍照取证** | 贴近真实作业；护眼；材料可复用 | OCR/拍照噪声；需授权与脱敏 | **主路径（推荐）** |

**推荐主路径 C 的理由**：

1. 学生本就有学校作业、卷子、教辅——AI 应服务真实材料，而不是再造第二套题海。  
2. 长时间 PC/手机刷题违背护眼与专注；屏幕会话应**短、可关、有目的**。  
3. 通过“已有材料盘点 + 每日作业拍照/要点反馈”，学情更真，计划才调得动。  
4. 购书/补卷建议只做**可选顾问**，最终由学生/监护人决定，系统不导购绑架。

#### 3.4.1 总览：纸质优先内容闭环

```text
友好沟通（目标/时间/薄弱点，可跳过）
  → 学习材料盘点（已有卷子 / 教辅 / 学校作业 / 缺什么）
  → AI 建议：今晚练哪几页、是否需要补某类卷子（可拒绝）
  → 学生离开屏幕，纸笔完成
  → 手机短时回传：拍照作业/错题 或 结构化反馈
  → AI 识别题意/作答区域（OCR/视觉理解）+ 学生确认卡点
  → 对照：材料自带答案页 / 学生标注正误 / 教师批改 / AI 辅助诊断（非答案机）
  → 解析：先提示策略与错因，再可选分步讲解
  → 写入孪生掌握证据 → 动态计划（学生确认）
```

**屏幕时间预算（产品约束）**：冷启动/材料盘点/每日复盘建议单次数分钟级；**不设计“连刷 30 题屏上卷”**。

#### 3.4.2 题目从哪来？（不再以系统题库为主）

| 来源 | 角色 | 说明 |
|---|---|---|
| 学生已有纸质卷子/教辅/学校作业 | **主来源** | 沟通盘点 + 可选封面/目录拍照建档 |
| 每日真实作业页 | **主练习载体** | 学生纸笔完成后再拍照或反馈 |
| AI 材料建议（买/不买/先用现有） | 顾问 | 基于缺口与目标；可拒绝；不做商城闭环 |
| 学科包知识图谱 + 错因/策略模板 | **诊断脚手架** | 帮助归类卡点与建议练法，**不是**把学生拉进内置刷题 |
| 系统内置样例题 | 仅 Demo/无材料冷启动兜底 | 明确标注示例；鼓励尽快切到真实材料 |

#### 3.4.3 答案从哪来？

| 类型 | 来源 | 用法 |
|---|---|---|
| 教辅/卷子自带答案页 | 学生/家长已有 | 鼓励先自批；可拍答案页辅助核对（可选） |
| 教师批改痕迹 | 纸质上的对错勾画 | 拍照识别“已批/未批/错题圈” |
| 学生自报正误 | 短反馈 | “这题我对了/错了/不确定” |
| AI 辅助判定 | 视觉+题意理解 | **辅助诊断**，置信度标注；不确定则问学生，不装全知 |
| 系统标准答案库 | **非主依赖** | 不为完整题库服务；避免答案机 |

**立场**：目标是帮助学生**看懂错在哪、下一步练什么**，不是替他抄答案。

#### 3.4.4 学生怎么输入？（短时屏幕 + 纸质主路径）

| 阶段 | 输入方式 | 屏时 |
|---|---|---|
| 了解学情 | 友好对话 / 单题 Modal（可跳过） | 短 |
| 材料盘点 | 选择已有材料类型 + 可选拍封面/目录 | 短 |
| 今日任务确认 | “做《XX》P12–13”确认/改期/缩量 | 极短 |
| **主学习** | **纸笔离屏完成** | **接近 0 屏** |
| 回传证据 | 手机拍作业/错题；或语音/表单说卡点 | 短 |
| 复盘协商 | 看 AI 建议的错因与明日计划，确认/拒绝 | 短 |

Modal 仍用于**结构化短决策**（开始/稍后、材料是否够用、明日是否换页），**不用于长时间屏上做整套题**。

#### 3.4.5 解析从哪来？

| 层级 | 来源 | 何时 |
|---|---|---|
| 学生先想 | 引导提问：“你卡在读题、列式还是计算？” | 拍照后先问 |
| 策略提示 | 学科包错因/策略模板 + 教练话术 | 识别到卡点类型 |
| 分步讲解 | L2 模型绑定题目图片区域与知识点假设 | 学生要“讲一步” |
| 材料解析 | 卷子/教辅自带解析（若有） | 提示学生去看对应页，系统不替代版权内容全文搬运 |
| 禁止 | 无确认的完整答案倾倒；把拍照当监控 | — |

#### 3.4.6 知识点掌握从哪些渠道知道？

| 渠道 | 证据 | 置信 |
|---|---|---|
| 每日作业拍照 + 错题分布 | 事实层过程证据 | 中–高（需学生确认难点） |
| 连续多日同类错因 | 趋势 | 中 |
| 材料进度（做到哪一章/哪一页） | 覆盖度 | 中 |
| 自批/师批正误 | 事实 | 高 |
| 短自评“这题我其实会/不会” | 自评 | 低–中 |
| 可选姿态/精力 | 仅调节任务量 | 不得当掌握依据 |

原则不变：**完成 ≠ 掌握**；一次拍照不错 ≠ 长期会；覆盖不足只轻调计划。

#### 3.4.7 材料建议（含是否购买）怎么做才不越界

```text
已有材料清单 + 目标缺口
  → 优先：“先把现有《同步练习》第3章错题订正”
  → 若缺口明显：可选建议“可考虑一本函数专项卷（非必须）”
  → 学生/监护人确认；系统不下单、不返佣叙事、不制造焦虑购买
```

#### 3.4.8 端到端示例（小林 · 纸质优先）

1. **沟通**：半年数学想轻松一点；晚上约 40 分钟；函数图像总混。  
2. **材料盘点**：已有学校练习册 + 一本教辅；没有专项卷。  
3. **建议**：今晚先做练习册 P18–19（图像与解析式）；**不必新买**；若连续一周同错因再考虑专项。  
4. **离屏纸笔**：小林完成两页。  
5. **拍照回传**：拍错题 3 道 + 选择“对称轴总搞错”。  
6. **诊断与解析**：AI 归类错因 → 给 2 步提示 → 建议明日只订正同类 4 题，不扩新题。  
7. **掌握与计划**：写入 `math.function.graph_mapping=emerging`；计划滚动，学生确认。  
8. **屏时**：沟通+盘点+拍照复盘合计短时；主体学习在纸上。

## 4. 产品形态与交互设计

### 4.1 信息架构

```text
┌──────────────┬─────────────────────────────┬──────────────┐
│ 左侧任务列表  │ 中间任务对话（引导/过程/反馈） │ 右侧情境面板  │
│ 点开即主动学  │ + 上层 Interactive Modal     │ 链路/知识点   │
└──────────────┴─────────────────────────────┴──────────────┘
```

### 4.2 Modal-first 原则

| 规则 | 说明 |
|---|---|
| 选择必弹窗 | 单选/多选/是否确认 |
| 填写必弹窗 | 填空、简答、线下反馈表单 |
| 阻塞等待 | `awaiting_user_input` 时不假装已答、不自动跳步 |
| 未提交不判错 | 关闭未提交 = 取消/稍后，可再次打开 |
| 回显可追溯 | 提交写入对话回显 + InteractionEvent |

### 4.3 主动交互但不打扰

| 场景 | AI 行为 | 学生选项 |
|---|---|---|
| 学习启动 | “到点了，想现在开始还是晚点？” | 开始 / 稍后 / 改期 / 暂停 |
| 执行后反馈 | “哪一步最卡？下一步想怎么安排？” | 结构化选择、简答、跳过 |
| 连续受阻 | “要不要换个更轻的练法？” | 尝试新方法 / 保持 / 稍后 |
| 节奏偏离 | “时间是不是不太合适？” | 改时间 / 缩短 / 暂停 / 关提醒 |
| 周期回顾 | “先听你怎么看这周，再给你看证据” | 确认 / 调目标 / 选优先项 |
| 孪生采集 | 先说明用途 + 单题 + 可跳过 | 跳过不写负向默认 |

**频控**：默认每日主动学习消息 ≤ 2 次；“稍后/暂停/静默/免打扰”立即生效。

### 4.4 手机端入口（姿态与随身反馈）

- 学习任务进行中可打开「姿态辅助」开关  
- 提醒以轻量卡片/弹窗出现，不中断到无法学习  
- 与桌面教育 IDE 共享同一学生孪生与计划，避免多端画像分裂

## 5. Agent 能力设计

### 5.1 多 Agent 协作

```text
                         AI 学习教练
                               │
                   Supervisor Agent（主管）
                               │
      规划 Agent · 陪伴 Agent · 成长分析 Agent · 干预策略 Agent · 安全合规
                               │
                       学生数字孪生
                               │
              线上学习 · 结构化交互 · 线下反馈 · 可选语音 · 可选手机姿态
```

| Agent | 职责 | 不可做 |
|---|---|---|
| Supervisor | 事件路由、调度、解释汇总 | 绕过确认、直接改高影响状态 |
| 学习规划 | 阶段/周计划、任务拆解 | 承诺提分、排满不可执行计划 |
| 陪伴沟通 | 主动启动、反馈采集、鼓励 | 高频催促、羞辱比较 |
| 成长分析 | 可解释洞察与置信度 | 把推断当事实、心理诊断 |
| 干预策略 | 可选策略与预期影响 | 强制改计划、惩罚未完成 |
| 安全合规 | 过滤、频控、风险升级 | 替代专业救助 |

### 5.2 Agent 应用闭环（对照手册 8.2）

| 环节 | 本系统落地 |
|---|---|
| 任务输入 | 目标、时间窗、任务反馈、线下证据、可选语音文本、可选姿态类别事件 |
| 意图理解 | 识别目标、约束、风险与是否需要行动 |
| 任务规划 | 阶段路线 + 周任务 + 是否需工具/确认 |
| 能力调用 | 知识图谱/学科包、规则引擎、模板、L2 模型编排、可选端侧姿态估计 |
| 结果交付 | 计划、任务卡、策略选项、成长回顾、可追溯依据 |
| 验证反馈 | 学生确认、事件日志、样例 Demo、评测指标 |
| 安全边界 | 不诊断、不替代评价、高风险转介、授权可撤回 |

### 5.3 快慢路径（产品体验关键）

| 路径 | 时延目标 | 用途 |
|---|---|---|
| L0 规则 | < 200ms | 写事件、切状态、开弹窗、频控 |
| L1 模板/轻量 | 通常 < 2s | 话术、选项、简单规则洞察 |
| L2 深度 Agent | 异步 | 周计划、复杂诊断、长解释 |

**硬规则**：点击必有即时反馈；到点提醒不依赖完整多 Agent 串行；L2 可取消/失败降级到 L1。

## 6. 学生数字孪生（个性化中枢 · 强化版）

### 6.1 不是什么 / 是什么

- **不是**：一次问卷档案、成绩预测器、人格打标签、监控学生的黑箱  
- **是**：在**多次交流与多源证据**中持续生长的可解释成长模型  
- **关键作用**：让反馈“说到位”、让计划“调得动且调得对”

### 6.2 双层结构

```text
StudentTwin
├── 相对稳定层：身份授权、目标、知识、兴趣与支持偏好
├── 五维动态层：目标计划 / 执行投入 / 认知策略 / 监控反思 / 动机情感
├── evidence_ledger（对话 / 任务 / 线下 / 可选姿态事件）
├── intervention_history
└── growth_timeline
```

### 6.3 五维状态（按学科/目标/时间窗，禁止全局人格分）

1. 目标与计划管理  
2. 学习投入与执行调节（可融合任务行为 + 可选姿态投入线索）  
3. 认知理解与学习策略  
4. 自我监控与反思调节  
5. 动机、自我效能与学习情感（以主动自评为主；姿态不直接等于情绪诊断）

原则：**事实 / 自评 / 推断分层**；动态状态有有效期；学生可见、可解释、可更正；**覆盖度不足时不强行下结论**。

### 6.4 采集难度对比与落地抓手

完整对比表见 **§2A.2**。工程抓手：

- 用 **心理学友好话术 + Modal 选择题** 降低防御与填表负担  
- 用多次短交互代替一次长问卷（自主感 + 低负荷）  
- 问前说明用途、答后即时回馈用途（透明 + 微承诺）  
- 跳过/更正/过期机制，防止负面永久标签  
- 用可选姿态补“身体侧信号”，但默认关、可忽略，不替代主路径  

### 6.5 孪生如何驱动动态计划（一句话）

> 孪生提供“学生此刻可能需要什么”的**有证据假设**；动态计划引擎把假设变成**可确认的下一步**；没有孪生，计划只能死板，反馈只能空泛。

## 7. 技术路线与数据

### 7.1 技术栈方向（初赛说明，复赛落地）

| 层 | 方案 |
|---|---|
| 产品形态 | 短时教练端（桌面/手机）+ **纸质主学**；非题库刷题 App |
| 编排 | Supervisor + 子 Agent；L0/L1/L2 路由 |
| 模型 | 可插拔大模型（开源/商业均可，需披露） |
| 知识增强 | 学科包：知识图谱 + 错因/策略模板 + 材料任务脚手架（非内置刷题库） |
| 内容闭环 | **已有纸质材料** + 拍照/反馈取证 + 掌握证据账本 |
| 交互 | 短时 Modal 确认；手机拍照回传；屏时预算约束 |
| 数据 | 本地优先事件账本 + 孪生摘要缓存 |
| 语音（可选） | 转写→编辑→提交；不做声学情绪分析 |
| 姿态（可选） | 手机摄像头端侧姿态类别估计；默认不存原视频 |
| 视觉（作业） | 作业/错题拍照 OCR 与区域理解；图默认可删；需授权 |

### 7.2 工具 / 系统依赖

- 教育编排接口：`edu_initialize_student_twin`、`edu_generate_learning_plan`、`edu_enqueue_interaction`、`edu_submit_offline_feedback`、`edu_propose_intervention` 等  
- 材料盘点与建议：`edu_inventory_learning_materials`、`edu_propose_material_purchase`（可拒绝）  
- 作业证据：`edu_submit_homework_photo`、`edu_diagnose_homework_evidence`  
- 学科包：知识图谱/错因策略脚手架，**不是**长时间屏上题库  
- 可选：语音转写服务（可关、可删原始音频）
- 可选：手机端姿态估计（默认关；结构化标签入账）

### 7.3 数据来源（初赛）

| 类型 | 来源 | 说明 |

| 学生输入 | 目标、反馈、自评 | 用户主动提交 |

## 8. 合规边界与风险提示

1. **辅助定位**：系统输出为学习支持建议，不替代教师、学校、专业机构最终判断。  
2. **未成年人保护**：监护人授权、最小采集、用途限定、可导出/删除。  
3. **不直接给标准答案作为主路径**：鼓励提示、追问、分步讲解与同类练习。  
4. **姿态辅助边界**：默认关；非身份识别；不用于惩罚/告状；默认不存原视频。  
5. **高风险表述**：停止常规编排，提示寻求现实中可信成人/专业支持。  
6. **可追溯**：计划调整可回溯到事件、反馈、可选姿态线索与规则版本。  
7. **开放披露**：第三方模型/API、许可证与权限范围将在工程材料中完整披露。

## 9. 创新点与差异化

| 常见产品 | 本项目 |
|---|---|
| 一次问卷/静态档案 | **多次交流生长的数字孪生**（可见可改） |
| 死板周计划/打卡表 | **孪生驱动的动态可协商计划** |
| 完成率当学情 | 事实/自评/推断分层 + 覆盖度 |
| 学生先想怎么问 | 点开任务 / 到点，AI 主动引导 |
| 聊天框猜格式答题 | Modal-first 结构化交互 |
| 抽象刷题 | 真实场景任务 + 知识点显式调用 |
| 内置题库长时间刷屏 | **纸质主学 + 材料盘点 + 拍照取证**（屏时受控） |
| 答案机 | 先策略提示与错因；答案页/师批优先，AI 辅助诊断 |
| 只判对错 | 分析 → 策略 → 学生可选干预 |
| 只看 App 内刷题 | **真实纸质作业闭环** + 可选姿态 |
| 监控式摄像头 | 可选姿态辅助：默认关、本地优先、不惩罚 |
| 慢 Agent 卡顿 | L0/L1 即时 + L2 异步降级 |

## 11. 评测与成功标准（初赛可说明）

| 目标 | 可衡量结果 |
|---|---|
| 目标清晰 | 初始化后至少 1 个长期目标 + 阶段目标 + 本周任务 |
| 计划可执行 | 任务含时长、时间窗、证据与调整规则 |
| 主动干预有效 | 学生可明确选择开始/稍后/改期/暂停，系统不擅自推进 |
| 状态可追溯 | 每次调整可回溯证据 |
| 内容可追溯 | 题目/答案键/解析/掌握证据均可指向学科包与事件 |
| 纸质优先 | Demo 主路径为离屏纸笔 + 短时回传，而非屏上刷题 |
| 屏时克制 | 单次教练会话有目的、可结束；不诱导长时间盯屏 |
| 体验顺畅 | 关键点击即时反馈；未提交弹窗不推进 |
| 合规可控 | 授权、更正、导出、删除路径清晰 |

## 13. 路演收束语

> 我们不做催学机器人，也不做替学生交答案的工具。  
> 我们做会生长的数字孪生，而不是一次问卷档案；  
> 我们做动态可协商的计划，而不是死板课表；  
> 我们把学科题怎么来、答怎么来、解析怎么来、掌握怎么判说清楚——不是答案机，而是可追溯的自学教练；  
> 我们让学生在**纸上**完成主学习，屏幕只做短时教练：沟通、材料建议、拍照复盘；  
> 我们用心理学友好的方式收集信息——尊重自主、保护面子、可跳可改，而不是测评审讯；  
> 我们让反馈和调计划都站在“真正理解学生”之上——必要时用手机姿态辅助，但默认尊重授权与拒绝权。  
> 最终，帮助学生成为自己的学习管理者。
