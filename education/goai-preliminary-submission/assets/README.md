# assets 资源目录

用于放置项目的可视化与验证材料。

## 建议结构

```text
assets/
  screenshots/     # 关键界面截图
  video/           # Demo 视频文件或 link.txt
  prototype/       # 原型链接、线框导出
```

## 命名建议

- `01-onboarding.*` 建档
- `02-plan.*` 计划
- `03-proactive-modal.*` 主动启动弹窗
- `04-offline-feedback.*` 线下反馈
- `05-intervention.*` 干预确认
- `06-weekly-review.*` 周回顾

## 注意

- 请使用模拟学生数据，避免真实未成年人隐私出镜
- 截图中如含 API Key、本机绝对路径、真实手机号等请打码
