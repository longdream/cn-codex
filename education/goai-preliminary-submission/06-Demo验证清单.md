# Demo 场景验证说明

本文档说明核心学习闭环的演示场景、验证重点与可视化资产。

---

## 1. Demo 目标

用 **3–5 分钟**讲清一条完整闭环：

```text
友好沟通 → 材料盘点 → 纸质页码任务 → 离屏完成
→ 拍照/反馈 → 错因诊断 → 动态计划确认 → 成长回顾
```

---

## 2. 推荐 Demo 脚本（小林 · 数学）

| 序号 | 画面/操作 | 讲解要点 | 证据类型 |
|---|---|---|---|
| 1 | 首次对话建档 | **心理学友好开场**：“半年后希望哪里轻松一点？”可跳过；非测评口吻 | 截图/视频 |
| 1b | 再次交流补充 | 展示孪生**覆盖度上升/字段更新**（强调会生长） | 截图 |
| 1c | 材料盘点 | 已有练习册/教辅；AI 建议先用现有，不急买新卷 | 截图 |
| 2 | 画像摘要确认 | 学生可编辑、确认“这是我当前情况” | 截图 |
| 3 | 首周骨架计划 | 任务落到**纸质页码**；旁白：不是内置题库刷屏 | 截图 |
| 4 | 到点主动弹窗 | 开始/稍后/改期/暂停 | 视频关键 |
| 5 | 确认后离屏 | 旁白强调：**去写纸质作业**，不连刷屏上题 | 视频 |
| 6 | 纸质完成 | 练习册真实页 | 旁白/实拍 |
| 6b | 拍照回传 | 2–3 道错题照片 + “哪一步最卡？” | 视频 |
| 7 | 反馈表单 | “哪一步最卡？”+ 可跳过信心项；跳过不写负向 | 视频 |
| 8 | 洞察与建议 | 不直接给答案；映射练习策略 | 截图 |
| 9 | 学生确认调整 | 明日任务变更可追溯 | 截图 |
| 9b | 依据展示 | 明确展示“依据孪生证据/快照”，无孪生则无法这样调 | 截图 |
| 10 | 周回顾 | 先学生自评，再系统证据汇总 | 截图 |
| 11 | （可选）姿态辅助 | 手机开启→趴伏类别→温和提醒→可选缩时/忽略 | 视频 |

### 2.1 心理学友好采集演示要点

1. 问前有用途说明（“为了把明天安排得更合适”）  
2. 单轮一问 + 跳过/稍后按钮可见  
3. 学生点跳过后，系统**不**出现负面评价  
4. 画像可改，改完后计划建议跟着变

## 4. 异常与边界分支

| 分支 | 期望表现 |
|---|---|
| 今天暂停 | 当日不再催促；温暖确认 |
| 稍后开始 | 到选定时间前不重复催 |
| 关闭弹窗未提交 | 不判错；可再次打开 |
| 跳过信心/精力 | 不写默认负向状态 |
| L2 超时 | 仍可选改期/缩短/保持 |
| 连续同类错因 | 给可选策略，不强制 |
| 高风险表述（脚本化演示） | 停止常规编排 + 求助提示（勿用真实危机内容做娱乐化表演） |

    demo-3min.mp4            # 2分42秒 1080p：片头 + 6 屏运镜 + 步骤字幕 + 片尾边界声明

再生成方法：

- 原型截图：Edge 无头模式 `--screenshot --window-size=1440,900` 逐个截取 `prototype/*.html`（注意系统 DPI 缩放会使输出像素翻倍，视频脚本已兼容）；
- 视频：运行 `assets/video/build-video.ps1`（需 ffmpeg），自动完成截图运镜、字幕烧录与拼接。

## 6. 视频呈现要点

- 分辨率 ≥ 1080p；UI 字体清晰  
- 开场呈现：项目名称与一句话价值
- 避免刷屏式聊天；突出**弹窗结构化交互**  
- 字幕标注 Agent 步骤（规划/陪伴/分析/干预）  
- 片尾声明：模拟数据、辅助定位、不替代教师评价
