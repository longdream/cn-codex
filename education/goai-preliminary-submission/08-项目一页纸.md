## 选择赛题与目标场景

- **赛道**：无界应用｜Boundless Agents  
- **赛题**：AI+教育  
- **场景**：**纸质主学 + 短时屏幕教练** + 材料盘点 + 拍照取证 + 动态计划 + 会生长孪生  

## 目标用户与核心问题

- **用户**：初中自学学生（主），授权家长/教师（辅）  
- **问题**：计划死板；刷题 App 盯屏过久；真实卷子/作业未被系统理解  

## 方案概述与核心流程

**纸质优先**：沟通了解学情 → 盘点已有卷子/教程 → 建议练哪页/是否补材料 → 离屏纸笔 → 短时拍照复盘 → 动态计划：

```text
友好沟通 → 材料盘点 → 纸质任务 → 离屏完成 → 拍照/反馈
→ 错因诊断 → 孪生更新 → 动态计划（学生确认）→ 成长回顾
```

**为什么必须有孪生**：没有持续、可解释的状态把握，反馈只能空泛，计划只能死板；孪生是“调得对”的前提。  

**为什么采集必须心理学友好**：学生越觉得被测评/监控，越被动、越假回答；自主、能力、关联三感与可跳过/可更正，是孪生数据可信的前提。  

**学科内容如何闭环**：题=已有纸质材料；学=纸笔离屏；证=拍照/反馈；答=答案页/师批/自批+AI 辅助；解析=策略先于结论；掌握=多源证据。  

## Agent 架构与关键能力

- Supervisor 路由 + 规划 / 陪伴 / 成长分析 / 干预 / 安全  
- 心理学友好采集（用途说明、单题、可跳过、非评估话术）  
- 孪生生长（覆盖度、有效期、可更正）+ 动态计划建议—确认—回写  
- 纸质任务与作业照片证据契约；材料盘点与可选购书建议  
- 可选手机姿态类别（端侧、默认可关）  
- L0/L1/L2 快慢路径  

## 数据来源、工具调用与技术路线

- 数据：多轮交互证据 + 线下反馈 + 模拟 Demo + 学科包 + 可选姿态类别  
- 工具：知识图谱/任务模板、事件账本、可选 STT、可选端侧姿态、CN-Codex 运行时  
- 技术：教育 IDE + 手机辅助入口 + 编排状态机 + 本地优先

## 安全合规边界

辅助学习，不替代教师评价；未成年人分级授权；姿态默认关、不惩罚不告状、默认不存原视频；动态计划高影响变更必须学生确认。
