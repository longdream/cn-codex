## 5. 初赛叙事一句话

> 以**会生长的学生数字孪生**把握状态，驱动**动态可协商计划**与有依据反馈；多 Agent 主动陪伴 + Modal-first 交互 + 线上线下闭环；可选手机姿态辅助——而不是死板课表或答题机器人。

> v1.4 起主叙事升级为：**纸质主学、短时屏幕教练**——沟通建档、材料盘点、页码任务、拍照取证；**不以系统内置题库长时间刷屏**。

### v1.1 强化的三大特色

1. **数字孪生多次交流生长** vs 一次问卷/静态档案（含采集难度对比）  
2. **动态计划** vs 传统一次性学习计划（孪生是调计划的前提）  
3. **可选手机端学习姿态感知**（授权、端侧、不惩罚、不存原视频）  

### v1.2 补强：心理学友好采集（防被动/反感）

- 支持性收集，非评估审讯  
- 自主感 / 能力感 / 关联感 + 透明用途 + 低负荷单题  
- 跳过≠差评；可更正；禁用测评羞辱话术  
- 见方案书 §2A.3 与 SPEC §5.6.1  

### v1.3 补强：学科内容闭环（题/答/解析/掌握）

- 题目：官方学科包 task-templates / demo（非完整商业题库）  
- 答案：包内 answer_key / rubric，默认不直出完整答案  
- 输入：Modal-first；聊天非正式评分主路径  
- 解析：hint_ladder + 错因模板 + 可选 L2 绑定知识点讲解  
- 掌握：多源证据 + 覆盖度；完成≠掌握  
- 见方案书 §3.4 与 SPEC §8.1–8.8  

### v1.4 转向：纸质优先（护眼 + 真实材料）

- 主学习 = 学生已有卷子/作业纸笔完成  
- 屏幕 = 短时沟通 / 材料建议 / 拍照复盘（有屏时预算）  
- 题目主来源从“系统题库”改为“已有纸质材料”  
- 作业照片 + 错因诊断驱动掌握与动态计划  
- 购书建议可拒绝；非商城导购  
- 见方案书 §3.4 与 SPEC §8 / §9
