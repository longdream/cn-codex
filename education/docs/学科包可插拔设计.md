# 学科包可插拔设计文档

> 对应主需求：`education/docs/教育IDE_需求文档_可参赛版.md` 第 17 章。  
> 本文用于补充包目录、Schema 示例与演进说明；与主文档冲突时以主文档第 17 章为准。

## 1. 设计目标

- **学科不是硬编码**：学科（数学、语文、英语等）不嵌入教育核心引擎，而是通过**学科包**实现可插拔。
- **自动安装与启用**：学生在初始化或设置中选择学科后，系统自动启用对应内置官方学科包。
- **包内容边界**：第一期聚焦**知识图谱 + 任务模板 + 错因分类**；练习题、教材资源、媒体文件后续按需扩展。
- **隔离与安全**：每个包独立目录，内容通过结构化 JSON/YAML 声明；包内不包含可执行代码。
- **兼容性**：新安装的包不影响已启用学科、学生历史任务、学习证据和数字孪生。

## 2. 包目录结构（推荐实现）

```text
education/
  subject-packs/                          # 内置学科包目录
    junior-math/                          # 初中数学
      manifest.json                       # 包元信息清单
      knowledge-graph.json                # 知识图谱（节点、关系、先修关系）
      task-templates.json                 # 任务模板（场景、知识点绑定、交互弹窗配置）
      error-taxonomy.json                 # 错因分类与反馈字段
      demo/                               # 可选演示资源（题目示例、图片）
    junior-chinese/
      manifest.json
      ...
    junior-english/
    ...
```

### manifest.json 示例

```json
{
  "id": "junior-math",
  "name": "初中数学",
  "version": "1.0.0",
  "subjects": ["junior-math"],
  "grades": ["7", "8", "9"],
  "supported_tools": ["knowledge_graph", "task_generator", "error_analyzer"],
  "resources": {
    "knowledge_graph": "knowledge-graph.json",
    "task_templates": "task-templates.json",
    "error_taxonomy": "error-taxonomy.json"
  }
}
```

## 3. 启用与卸载流程

### 启用流程（学生初始化或设置中）

```text
1. 学生选择学科（数学 / 语文 / 英语）
2. SubjectPackageRegistry 扫描内置 subject-packs/<id>
3. 校验 manifest.json 与资源文件完整性
4. 写入 student_subject_enrollments（已启用列表）
5. 提供学科上下文给：
   - 规划 Agent（生成该学科计划）
   - 成长分析 Agent（分析该学科知识状态）
   - 干预策略 Agent（学科特定干预）
6. 界面显示：目标页、计划页、画像页按学科筛选
```

### 卸载流程

- 只从 `student_subject_enrollments` 中删除对应记录
- **不删除**已生成的任务、学习证据、数字孪生历史数据
- 后续重新启用时可恢复

## 4. 与现有架构的集成点

- **Student Digital Twin**：`subject` 字段存储已启用学科
- **Learning Plan Agent**：读取对应学科的任务模板，生成跨学科/单学科计划
- **Interaction**：任务弹窗可根据学科包中的 `task-templates.json` 动态生成
- **Knowledge Model**：错因分类存储在包中，统一查询

## 5. 扩展性

- 未来可支持**远程包仓库**（下载 + 签名校验）
- 包内可扩展的字段：`custom_tools`, `strategy_prompts`
- 包版本管理（semantic versioning）
